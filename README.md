# 1C-Web.Uz

Веб-система для сервиса аренды/аутсорсинга 1С в облаке (рынок Узбекистана).
Клиент размещает свою базу 1С на нашем сервере и работает с ней из любой точки —
из офиса, из дома или в отпуске.

Стек: **Next.js 14** (Pages Router) + React 18, Swiper, lucide-react. Двуязычность RU/UZ.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшн-сборка
npm run start   # запуск собранной версии
```

## Структура

```
pages/
  _app.js          # обёртка: AppProvider + глобальные стили + Swiper CSS
  _document.js     # <html lang>, шрифты Google, Open Graph
  index.js         # лендинг: собирает секции по порядку
  api/lead.js      # приём заявок с формы (сейчас — лог; точка расширения)
components/
  AppContext.js    # контекст: язык (RU/UZ) + управление модалкой заявки
  Layout.js        # <Head>, шапка, футер, модалка
  Header.js        # шапка + переключатель языка + мобильное меню
  Footer.js
  Logo.js
  LeadModal.js     # форма заявки (имя, телефон, компания, тариф, коммент)
  Reveal.js        # плавное появление секций при скролле
  sections/        # Hero, Clients, Features, Pricing, Steps, Testimonials, Faq, FinalCta
lib/
  translations.js  # ВЕСЬ контент лендинга на RU и UZ + контакты
styles/
  globals.css      # дизайн-система (цвета 1С) и стили всех секций
```

## Как менять контент

- **Тексты, тарифы, FAQ, отзывы** — `lib/translations.js` (RU и UZ рядом).
- **Контакты (телефон, e-mail, адрес, соцсети)** — объект `contacts` в том же файле.
- **Цвета/типографика** — CSS-переменные в начале `styles/globals.css`.

## ⚠️ Плейсхолдеры (заменить перед публикацией)

## Личный кабинет (прототип)

Кабинет клиента доступен по адресу `/login` → `/cabinet`.

**Демо-доступ:** `demo@1c-web.uz` / `demo1234`

Разделы:
- `/cabinet` — обзор: статус подписки, тариф, следующий платёж, метрики.
- `/cabinet/databases` — базы 1С клиента и данные для подключения.
- `/cabinet/billing` — счета со статусами (оплачен / ожидает / просрочен) и
  реквизиты для оплаты банковским переводом (модель «ручные счета»).
- `/cabinet/profile` — данные компании и тариф.

Как это устроено:
- `lib/mockDb.js` — **демо-данные в памяти** (клиенты, базы, счета, реквизиты).
- `lib/auth.js` — подписанная (HMAC) cookie-сессия; страницы защищены через
  `lib/withAuth.js` в `getServerSideProps`.
- `pages/api/auth/login|logout` — вход/выход.

> ⚠️ **Перед продакшеном** замените `lib/mockDb.js` на реальную БД, а демо-авторизацию
> (`lib/auth.js`) — на проверенное решение (NextAuth.js / iron-session) с хешированием
> паролей. Секрет подписи задаётся переменной окружения `SESSION_SECRET`.
> Реальные банковские реквизиты — в `paymentRequisites` (`lib/mockDb.js`).
